# LINE 美金到價 + 股票總結機器人（v4）

這版主要是 UX 整理，功能沒有變多，但指令更乾淨：

1. **美金日報改成自訂時間**：`美金日報 1030` 代表每天約 10:30 發送，不再綁在收盤總結的固定時間
2. **到價提醒指令合併**：美金跟股票共用同一組「提醒 / 提醒清單 / 刪除提醒」指令，用「美金」當目標名稱即可
3. **拿掉「分類」指令**：核心/衛星標籤只影響顯示、沒有實際功能，拿掉讓指令更精簡

---

## 完整指令列表

### 美金

- 「美金」查詢目前美金匯率
- 「美金兩週」查看近兩週的漲跌幅、高低點與日期
- 「美金日報 1030」開啟美金日報，每天約 10:30 發送（24小時制四碼，例如 0830、1330、2000）
- 「美金日報 關」關閉美金日報

### 到價提醒（美金、股票通用）

- 「提醒 美金 高於33」「提醒 美金 低於31」新增美金到價提醒
- 「提醒 2330 高於600」「提醒 2330 低於550」新增股票到價提醒（未加入清單會自動加入）
- 「提醒清單」查看全部到價提醒（美金 + 所有股票）
- 「提醒清單 美金」「提醒清單 2330」查看指定的到價提醒
- 「刪除提醒 美金 1」「刪除提醒 2330 1」用編號刪除

### 股票基本

- 「查詢 2330」直接查詢股價，不用先加入清單
- 「新增 2330」加入自選股清單
- 「刪除 2330」移除自選股

### 成本、停利停損、加碼

- 「成本 2330 550」設定持有成本
- 「損益 2330」查看目前損益 %
- 「停利 2330 15」漲到成本+15% 提醒
- 「停損 2330 8」跌到成本-8% 提醒
- 「加碼提醒 2330 10」跌到成本-10% 提醒（適合核心持股逢低加碼）
- 「成本提醒清單 2330」「刪除成本提醒 2330 1」

### 技術指標（波段操作輔助）

- 「技術提醒 2330 開」開啟均線交叉(5日/20日) + RSI過熱過冷通知
- 「技術提醒 2330 關」關閉

### 總覽

- 「清單」總覽所有設定
- 「說明」列出所有指令

## 美金日報的運作方式

美金日報不再是獨立的排程時間，而是**每 30 分鐘的到價檢查**（`/check-alerts`）裡順便判斷「現在時間有沒有接近你設定的時間」（容許 ±15 分鐘誤差，抓 30 分鐘一次的排程間隔），一天只會送一次，用 `lastReportSentDate` 記錄避免重複發送。

好處是**不用額外的 GitHub Actions 排程**，改時間也不用去改 `.github/workflows/cron.yml`，直接傳 LINE 指令就好。

---

## 排程總覽（沒有變動）

- 到價檢查（含美金日報判斷）：每 30 分鐘一次
- 開盤前總結：約 08:30
- 收盤後總結：約 13:30（不再附加美金匯率，因為美金日報已經獨立、可自訂時間了）
- 技術指標檢查：約 13:45

## 部署方式

跟之前一樣，push 上 GitHub、Render 自動重新部署。

⚠️ 這次美金設定的資料結構有小改：原本的 `dailyReportEnabled`（開關）換成 `dailyReportTime`（時間字串或 null）。部署後你原本的美金日報設定會失效（視為關閉），重新傳一次 `美金日報 1030` 這類指令設定時間即可，其他資料（到價提醒、股票清單、成本設定）都不受影響。
