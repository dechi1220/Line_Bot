# LINE 美金到價 + 股票總結機器人（v3）

v3 新增了針對 Core-Satellite 策略設計的功能：

- **核心持股**（長期不賣、定期定額）→ 用「成本 + 加碼提醒」在跌深時提醒你依計畫加碼
- **衛星持股**（波段操作）→ 用「均線交叉」「RSI 過熱過冷」當作趨勢轉變的輔助訊號

⚠️ **重要提醒**：均線交叉、RSI 都是公開、機械化的技術分析公式，機器人只是把「達到某個條件」這件事自動計算並通知你，**不是投資建議**，最終買賣判斷還是你自己決定。另外這裡的 RSI 是簡化版算法，數值可能跟券商 App 有些微差異，拿來當大方向參考就好。

---

## 新增指令

### 分類（純顯示分組用，方便你自己管理）

| 指令 | 說明 |
|---|---|
| `分類 2330 核心` | 標記成核心持股 |
| `分類 2330 衛星` | 標記成衛星持股 |

### 成本、損益、停利停損、加碼提醒

| 指令 | 說明 |
|---|---|
| `成本 2330 550` | 設定持有成本（之後所有 % 都是以這個為基準） |
| `損益 2330` | 查看目前價格對成本的損益 % |
| `停利 2330 15` | 漲到成本 +15% 時提醒 |
| `停損 2330 8` | 跌到成本 -8% 時提醒 |
| `加碼提醒 2330 10` | 跌到成本 -10% 時提醒（核心持股逢低加碼很適合設這個） |
| `成本提醒清單 2330` | 看這檔股票所有成本相關提醒（附編號） |
| `刪除成本提醒 2330 1` | 用編號刪除 |

同一檔股票可以同時設多組（例如停損 8% + 加碼提醒 15%），都是根據你設定的成本各自獨立計算，不會互相干擾。

### 技術指標（均線交叉 + RSI）

| 指令 | 說明 |
|---|---|
| `技術提醒 2330 開` | 開啟後，機器人會用收盤價每天檢查一次 5日/20日均線交叉、RSI 是否進出過熱(≥70)/過冷(≤30)區間，只有「狀態轉變」時才通知你 |
| `技術提醒 2330 關` | 關閉 |

開啟當下會先回你目前的狀態（例如「5日線在20日線之上，RSI 55 正常」），這一次不算通知，之後只有真正變化才會推播。

## 排程更新

新增了每日一次的技術指標檢查，時間排在收盤後總結之後：

- 到價/成本檢查：每 30 分鐘（不變）
- 開盤前總結：約 08:30
- 收盤後總結（含美金日報）：約 13:30
- **技術指標檢查（新）：約 13:45**，用當天收盤價檢查均線交叉跟 RSI

同樣可以在 GitHub Actions 頁面手動點 **Run workflow**，這次多了 `technical-check` 可以選來單獨測試。

## 建議的設定方式（對應你的策略）

**核心持股（0050、2330 這類）：**
```
新增 0050
分類 0050 核心
成本 0050 130
加碼提醒 0050 10
```
之後只要 0050 跌到成本 -10%，就會提醒你「可以依計畫加碼」，平常不會吵你。

**衛星持股（波段操作）：**
```
新增 2317
分類 2317 衛星
成本 2317 110
停利 2317 15
停損 2317 8
技術提醒 2317 開
```
這樣同時有「價格到停利/停損目標」跟「趨勢可能轉變（均線交叉/RSI）」兩層輔助，不用自己每天盯線圖。

## 部署方式

跟之前一樣，push 上 GitHub、Render 自動重新部署，環境變數跟 Webhook 都不用動。這次資料結構是在原本股票設定的 JSON 裡加欄位（不是換 key），所以**不會像上次一樣有型別衝突的問題**，既有的到價提醒、自選股清單都會照常保留。
